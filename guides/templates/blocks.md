# Branded blocks

The building blocks of every guide page. Paste them into Notion and they become callouts, quotes and dividers. Replace everything in [brackets]. The emoji at the start of a callout becomes its icon in Notion; set the color as listed in the playbook.

## Header (top of every page)

```
[Cover: Lina banner] [Icon: Almuri logo]

# [Title]

[One line: what you'll get and how long it takes.]
```

> 📁 **Free, no signup needed.** Everything is on this page. Prefer files? [Get them on GitHub](https://github.com/aka1127/almuri/tree/main/guides/[keyword]).
